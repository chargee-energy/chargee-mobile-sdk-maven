# Chargee SDK Maven repository

A plain [Maven repository layout](https://maven.apache.org/repository/layout.html) holding the
Android/JVM artifacts of the [Chargee Mobile SDK](https://chargee.energy), served over GitHub Pages.
It contains no source — everything here is generated by the SDK's release pipeline.

## Using it

```kotlin
repositories {
    mavenCentral()
    maven("https://chargee-energy.github.io/chargee-mobile-sdk-maven")
}

dependencies {
    implementation("energy.chargee:sdk:<version>")
}
```

iOS consumers do not use this repository: the SDK ships to them as a Swift package from
[`chargee-mobile-sdk-binaries`](https://github.com/chargee-energy/chargee-mobile-sdk-binaries).

## Rules

- **Versions are immutable.** The release pipeline refuses to overwrite one. Deleting a published
  version breaks every build that has resolved it.
- **Do not hand-edit.** Each release is committed by CI, which publishes straight into a checkout so
  that Gradle merges every `maven-metadata.xml` with the versions already here.
